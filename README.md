## Install Bun

Use the Bun install commands for your platform:

### macOS / Linux

```bash
curl -fsSL https://bun.sh/install | bash
```

### Windows (PowerShell)

```powershell
irm https://bun.sh/install | iex
```

After installation, restart your terminal and verify with:

```bash
bun --version
```
